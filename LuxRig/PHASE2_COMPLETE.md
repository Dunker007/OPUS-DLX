## 🎮 **How to Run**

### **1. Deploy to LuxRig Server**

```powershell
# Clone repository
git clone https://github.com/Dunker007/OPUS-DLX.git
cd OPUS-DLX
git checkout claude/build-phase-1-foundation-016PXJabGHeCPpTRL1FanGH3

# Deploy
Copy-Item -Path ".\LuxRig" -Destination "C:\" -Recurse -Force
```

### **2. Configure API Keys**

```powershell
cd C:\LuxRig\Configs
Copy-Item api-keys.json.template api-keys.json
notepad api-keys.json  # Add your actual API keys
```

### **3. Run Tests**

```powershell
C:\LuxRig\Tests\test-phase1.ps1
```

### **4. Start the Master Orchestrator**

```powershell
# Start autonomous mode (runs forever)
C:\LuxRig\Orchestrator\master-orchestrator.ps1 -Mode "auto" -Interval 3600

# OR run a single test cycle
C:\LuxRig\Orchestrator\master-orchestrator.ps1 -Mode "test"
```

### **5. Monitor with Dashboard**

```powershell
# Real-time monitoring
C:\LuxRig\Analytics\dashboard.ps1 -Continuous -RefreshInterval 10
```
