## 🔒 Security Best Practices

### **API Key Management**
```powershell
# NEVER commit API keys
# Use environment variables
$env:BINANCE_API_KEY = "your-key-here"
$env:BINANCE_API_SECRET = "your-secret-here"

# Or use config file (gitignored)
{
  "exchanges": {
    "binance": {
      "apiKey": "your-key-here",
      "apiSecret": "your-secret-here"
    }
  }
}
```

### **2FA Setup**
```powershell
# Enable 2FA for user
Import-Module ./Enterprise/Auth/user-manager.ps1
$result = Enable-TwoFactor -UserId "user123"

# Scan QR code with authenticator app
# Or manually enter: $result.manualEntry
```

### **Audit Log Review**
```powershell
# View recent audit log
Import-Module ./Enterprise/RBAC/permission-system.ps1
Get-AuditLog -Last 100

# Filter by user
Get-AuditLog -UserId "admin123" -Last 50

# Filter by action
Get-AuditLog -Action "TRADE_EXECUTED" -Last 100
```
