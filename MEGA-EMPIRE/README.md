## 🎯 Quick Start

### Prerequisites

- Python 3.8+
- 4GB RAM minimum (8GB recommended)
- 20GB disk space
- Linux/Mac (Windows WSL supported)

### Installation

```bash
# Clone the repository
cd MEGA-EMPIRE

# Install dependencies (if any)
# pip install -r requirements.txt

# Verify installation
python launcher.py --status
```

### Launch Options

```bash
# Start entire system (Master Control + all modules)
python launcher.py

# Start Master Control Center only
python launcher.py --master

# Start specific category
python launcher.py --category ContentFactory
python launcher.py --category RevenueEngines

# Start specific module
python launcher.py --module 1

# Check system status
python launcher.py --status

# Stop all modules
python launcher.py --stop
```

The Master Control Center is the brain of MEGA-EMPIRE, providing:

Commands:

## 🐛 Troubleshooting

### Module Won't Start
```bash
# Check module logs
tail -f Logs/mega_empire_YYYYMMDD.log

# Restart specific module
python launcher.py --module MODULE_ID
```

### High Resource Usage
```bash
# Check system status
python launcher.py --status

# Reduce concurrent modules in Config/system_config.json
```

### Database Issues
```bash
# Backup and reset database
cp Data/*.db Data/backup/
rm Data/*.db
python launcher.py  # Will recreate databases
```
